## Verification

To verify the figures in this folder match their sources, run from the repo root:

```bash
md5sum figures/fig04_pareto_frontier_ixi.png results/paper3/ixi_benchmark_20260221_045741/100pct_200vol/paper_figures/fig1_ssim_pareto.png
```

The two hashes should be identical. Repeat for any figure to confirm.

## Verification scripts

In addition to the figures themselves, this folder contains the original generation scripts:

- `make_fig3_pca.py` — regenerates the PCA projection (Figure 6)
- `make_fig6_dose_response.py` — regenerates the dose-response curve (Figure 9)
- `make_figs_8_9_sample_grids.py` — regenerates the sample grids (Figures 5, 11, 12)

These read the JSON metric files in `results/` and re-render the same figures, so you can independently reproduce any of them.
