# ---------------------------------------------------------------
# Notes on reproducibility:
#   - All entry points should call src/utils/set_seed.py:set_seed(seed)
#     before any RNG-using code. This sets:
#       * Python random.seed
#       * numpy.random.seed
#       * torch.manual_seed (+ cuda.manual_seed_all / mps.manual_seed)
#       * torch.use_deterministic_algorithms(True) (CUDA)
#       * CUBLAS_WORKSPACE_CONFIG = ':4096:8' (CUDA, required by
#         torch.use_deterministic_algorithms)
#       * torch.backends.cudnn.deterministic = True
#       * torch.backends.cudnn.benchmark = False
#     and returns a torch.Generator with the same seed for DataLoader use.
#
#   - Apple MPS has known non-determinism on some op variants
#     (notably reduction kernels). Numbers reported in the paper
#     are MPS-derived; CUDA reproduction is expected within the
#     tolerance band stated above. See README for details.
