# Reproducibility map

Every table and figure in the paper, and the result file it was computed from. Table and figure numbers follow the submitted manuscript. Every path below resolves in this repository.

Datasets and model weights are **not** in this repository (see [Large files](#large-files)). Everything needed to *verify the reported numbers* is. `python3 fixes/05_verify_all_numbers.py` recomputes the headline values from the files listed here.

## Verifying a number yourself

Every reported value can be recomputed from the JSONs without a GPU. For example, Table 12 at 64³ and its threshold contrast:

```python
import json, numpy as np
from scipy import stats

d = json.load(open('results/paper4/e10a_64_5seed/e10a_64_5seed_results.json'))
M = {k: np.array(v['dices']) for k, v in d['results'].items()}

for k, a in M.items():
    print(f'{k:12s} mean={a.mean():.4f}  std={a.std(ddof=1):.4f}  n={len(a)}')

t, p = stats.ttest_rel(M['unique_25'], M['unique_10'])   # threshold contrast
print(f'unique_25 vs unique_10: t={t:.2f}  p={p:.4f}')      # t=2.86, p=0.0245
```

## Notes on cross-file comparability

**1. Real-diversity denominators differ by experiment.** Every "% of real" value divides by the real-data pairwise-L1 diversity of its own dataset, resolution and conditioning setting. Always read `metadata.real_diversity` from the JSON you are using rather than assuming a global constant. Values: IXI 64³ = 0.08375; BraTS 64³ unconditional = 0.0500; BraTS 64³ conditional = 0.0451; BraTS 128³ = 0.0461.

**2. Ablation percentages.** The ablation JSONs store raw pairwise-L1 values together with percentages computed at run time against a different denominator. The percentages quoted in the paper are the raw values renormalised against the Table 3 denominators; `fixes/04_recompute_tables_5a_5b.py` performs that renormalisation and prints the reported values. Raw values are directly comparable across all files.

**3. The factorial is schedule-matched.** All four cells of Table 8, including Cell A (EMA + L2), were trained under the same recipe (80 epochs, batch size 4) and evaluated under one protocol; the Cell A checkpoint is `results/paper4/cd_2x2/ema_l2/final.pt`, produced by `fixes/01_retrain_cell_a.sh`. The main-benchmark Consistency Distillation checkpoint (150 epochs, batch 2) is a different model and is the one behind Tables 3 and 5.

**4. Two 128³ sample pools.** Table 4 (frontier) and Table 7 (manifold metrics) were computed from separate 5-seed generation runs of the same 128³ checkpoints, which is why their "% of real" diversity values for the same model differ slightly (e.g. 17% vs 15.2% for Consistency Distillation).

**5. Feature space matters for Recall.** Precision/Recall/Density/Coverage are reported in two feature spaces: the generator's own VQ-GAN encoder (raw 4,096-D and a PCA-128 projection of it) and the encoder of a tumour-segmentation teacher never exposed to the generative objective. Recall is degenerate for every method on BraTS at 64³ in the VQ-GAN space and discriminates cleanly in the teacher space (Shortcut FM 0.597 vs Consistency Distillation 0.000). Always state which space a value comes from.

**6. The 128³ teacher bottleneck is pooled.** BasicUNet's bottleneck is 32 channels at input/16 resolution, so it is 2,048-D at 64³ but 16,384-D at 128³. `fixes/07_manifold_metrics_128.py` average-pools the bottleneck to 4³, giving 2,048-D at both resolutions so that Tables 5 and 7 are comparable. Pass `--no-pool` to reproduce the unpooled values.

**7. Dose-response seed counts.** The 64³ dose-response was first run with five seeds and later extended to eight; both result files are released (`e10a_64_5seed_results_n5_backup.json`, `e10a_64_5seed_results.json`) and Appendix A.6 of the paper reports both.

## Environment

```bash
pip install -r requirements.txt
```

All experiments were run on Apple M-series GPUs via PyTorch MPS. The 128³ downstream training uses a hardened numerical recipe (reduced LR with warmup, `DiceCELoss(smooth_nr=0)`, NaN-gradient guard, gradient clipping) that is required on MPS and is documented in Appendix A.7 of the paper.
